# Product

## Register

brand

## Users

Developers, maintainers, and technical teams evaluating a portable documentation workflow for real codebases. They need to understand the operating model quickly, verify that the project is grounded in repository evidence, and install the right adapter without marketing friction.

## Product Purpose

Docs Forge explains and distributes a codebase-grounded documentation workflow for Codex, Claude Code, Antigravity, and AGENTS.md-compatible agents. Success means visitors can judge the workflow, find the correct installation path, and understand which documentation outputs it supports.

## Brand Personality

Technical, candid, and methodical. The site should feel like a well-made field manual: confident about what the tool does, explicit about evidence boundaries, and easy to inspect.

## Anti-references

Avoid generic AI-tool marketing, purple gradients, glassmorphism, inflated automation claims, rounded-icon card grids, and dark developer-tool styling used as a shortcut for credibility.

## Design Principles

- Show the operating model, not vague promises.
- Make installation paths copyable and verifiable.
- Preserve a visible relationship between claims and source.
- Treat privacy choices as part of product trust.
- Keep optional tracking and communications genuinely optional.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Preserve keyboard access, visible focus, readable contrast, reduced-motion support, plain-language consent choices, and mobile layouts that do not hide privacy controls.
